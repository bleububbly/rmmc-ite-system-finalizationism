RMMC ITE COMPLETE INTERACTIVE SYSTEM PROTOTYPE

This prototype was created from the source PHP and CSS in the uploaded rmmc-ite-system (2).zip. It demonstrates Admin, Officer, and Student views.

QUICK START
1. Double-click RMMC_ITE_Interactive_Prototype.html (you do not need a server, PHP, or MySQL).
2. Click Log in as Admin, Officer preview, or Student preview.
3. Use the left navigation and the buttons to explore each workflow.
4. You can switch roles using the selector above the preview.

WHAT YOU CAN DEMONSTRATE
- All role-based dashboards and navigation menus
- Student directory and add/edit/profile screens
- Officer directory with organization and position fields
- Events: list/add/edit/detail/delete confirmation
- Attendance: expand/collapse event, four checkpoints
- QR Scanner: manual check-in result and bulk import
- Bulk CSV/XLSX import: select event/slot, preview, confirm
- Fines and verified student payments, sample receipts
- Clearance search, eligibility review and approval path
- Admin semester setup, settings, and password resets
- Student QR, attendance, fines and clearance views
- First-login password-change and account recovery

IMPORTANT LIMITATION
This is a standalone visual prototype. Buttons navigate between example views, but it does not authenticate against PHP, read/write MySQL, operate the camera, verify real payments, or persist transactions. The PNG ITE department logo was copied from the uploaded project.

FIGMA EXPORT ASSETS
The screens/ directory contains 61 editable SVG reference screens (1440x900). prototype_flows.json records the destinations for the navigation and buttons. No live Figma canvas edits occurred because the Figma MCP Starter plan rate limit blocked design mutations.

Source project code and database were not modified.
